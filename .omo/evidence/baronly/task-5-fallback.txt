=== 4. LSPosed scope state ===
/data/adb/lspd/config/modules_config.db schema scope(module_pkg_name,app_pkg_name,user_id).
Current module com.cos.lspit.gesture scope = ONLY com.android.systemui.
com.android.launcher NOT in scope -> launcher process cannot be hooked today.

=== Candidate fix options (architecture decision REQUIRED - see plan) ===
A) [recommended] Add com.android.launcher to LSPosed scope; in launcher process hook
   OplusWindowManager.updateInvalidRegion; when barOnly=ON replace the homegesture_displayid_0
   rect list x-range with the bar band [center-width/2, center+width/2] (width = user
   barWidthDp*density); when OFF pass through unchanged. Survives launcher re-registration
   because hook re-applies on every call; toggle = config read at hook time.
B) [not recommended] Stay in SystemUI scope; reflection-call OplusWindowManager
   .updateInvalidRegion to override launcher's region. Risk: launcher re-registers on
   rotation/nav-mode/width events and overwrites the override; last-writer-wins semantics
   between different owning uids unverified; needs re-assertion triggers.

Verdict: barOnly must be implemented launcher-side (option A) to be reliable. This extends
the Xposed scope beyond com.android.systemui for the first time.
